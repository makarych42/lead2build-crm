## 🚀 Быстрый старт

### 1. Убедитесь, что вы на правильной ветке

\`\`\`bash
git branch
# Должно показать: * feature/nextauth-authorization
\`\`\`

Если нет:
\`\`\`bash
git checkout feature/nextauth-authorization
\`\`\`

### 2. Создайте .env файл

Создайте файл `.env` в корне проекта:

\`\`\`env
DATABASE_URL="postgresql://postgres:password@localhost:5432/lead2build_crm?schema=public"
NEXTAUTH_SECRET="put-your-32-char-secret-here"
NEXTAUTH_URL="http://localhost:3000"
NODE_ENV="development"
\`\`\`

**Важно:** 
- Замените `postgres:password@localhost:5432` на ваши данные PostgreSQL
- Для генерации секрета: `openssl rand -base64 32`

### 3. Примените миграции

\`\`\`bash
npx prisma migrate dev --name add_auth_system
\`\`\`

Или для dev:
\`\`\`bash
npx prisma db push
\`\`\`

### 4. Создайте пользователей

\`\`\`bash
npm run db:seed
\`\`\`

### 5. Запустите приложение

\`\`\`bash
npm run dev
\`\`\`

### 6. Войдите в систему

Откройте http://localhost:3000

- Пароль: `Admin123!`

**Тестовые пользователи (пароль: Test123!):**

## 🐛 Известные ограничения

1. **Email уникальность:** Email должен быть уникальным, дубликаты не допускаются
2. **Самоудаление:** Администратор не может удалить или заблокировать сам себя
3. **Seed повторный запуск:** Если admin уже существует, seed не создаст дубликаты
4. **PostgreSQL only:** Используется только PostgreSQL (не SQLite)
