# Lead2Build CRM - Статическая версия

## 📁 Содержимое папки public_html

Эта папка содержит готовые файлы для загрузки на хостинг Рег.ру:

- `index.html` - Главная страница (дашборд)
- `leads.html` - Страница управления лидами
- `.htaccess` - Настройки сервера Apache

## 🚀 Инструкции по развертыванию

### 1. Получите FTP данные
Зайдите в панель управления Рег.ру и найдите:
- **FTP хост** (обычно ftp.yourdomain.ru)
- **FTP логин** (имя пользователя)
- **FTP пароль**
- **Порт** (обычно 21)

### 2. Подключитесь по FTP
Используйте любой FTP клиент (FileZilla, WinSCP) или встроенный файловый менеджер в панели управления.

### 3. Загрузите файлы
Скопируйте все файлы из папки `public_html` в корневую папку вашего сайта на хостинге (обычно `public_html` или `www`).

### 4. Настройте домен
В панели управления Рег.ру:
- Привяжите домен `lead2build.ru` к вашему хостингу
- Убедитесь, что DNS записи настроены правильно

### 5. Проверьте сайт
Откройте `http://lead2build.ru` в браузере - сайт должен работать!
