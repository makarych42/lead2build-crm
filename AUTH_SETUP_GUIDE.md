## 🚀 Шаги для завершения настройки

### 1. Настройте переменные окружения

Создайте файл `.env` в корне проекта (если его нет):

\`\`\`env
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/lead2build_crm?schema=public"

# NextAuth.js
NEXTAUTH_SECRET="your-secret-key-here"
NEXTAUTH_URL="http://localhost:3000"

# Node Environment
NODE_ENV="development"
\`\`\`

**Важно:**
- Замените `user`, `password`, `localhost:5432` на ваши данные PostgreSQL
- Для генерации `NEXTAUTH_SECRET` используйте:
  \`\`\`bash
  openssl rand -base64 32
  \`\`\`
- Или online: https://generate-secret.vercel.app/32

### 2. Создайте и примените миграцию базы данных

\`\`\`bash
# Создать миграцию
npx prisma migrate dev --name add_auth_system

# Или для dev окружения (без миграций)
npx prisma db push
\`\`\`

### 3. Запустите seed для создания пользователей

\`\`\`bash
npm run db:seed
\`\`\`

## 🎯 Возможности системы

### Роли и права доступа

1. **ADMIN** (Администратор)
   - Полный доступ ко всем разделам
   - Управление пользователями
   - Просмотр истории входов и сессий
   - Блокировка/разблокировка пользователей

2. **SALES_MANAGER** (Менеджер по продажам)
   - Создание и управление лидами
   - Просмотр документов
   - Создание задач

3. **DOCUMENT_SPECIALIST** (Специалист по документам)
   - Загрузка и управление документами
   - Одобрение документов
   - Создание задач

4. **TECHNICAL_INSPECTOR** (Инженер-инспектор)
   - Технические обследования
   - Загрузка технических документов
   - Создание отчетов

5. **VOTING_COORDINATOR** (Организатор голосований)
   - Создание голосований
   - Регистрация в ГИС ЖКХ
   - Управление квартирами

6. **VOTING_MANAGER** (Координатор голосования)
   - Работа с собственниками
   - Сбор голосов
   - Подготовка протоколов

### Админ-панель (только для ADMIN)

В боковом меню появятся новые разделы:
- **👥 Пользователи** - управление пользователями
- **💻 Сессии** - активные сессии пользователей
- **📜 История входов** - журнал всех попыток входа

### Функции безопасности

- ✅ Хеширование паролей (bcrypt, 10 rounds)
- ✅ JWT токены с автоматическим обновлением
- ✅ HTTP-only cookies
- ✅ CSRF защита
- ✅ Проверка активности пользователя
- ✅ Блокировка пользователей
- ✅ История входов (успешные и неудачные)
- ✅ Управление сессиями
- ✅ Автоматический logout при блокировке

## 🔧 Troubleshooting

### Проблема: "Неверный email или пароль"
**Решение:** 
- Проверьте, что seed скрипт выполнен
- Используйте точные учетные данные (с учетом регистра)

### Проблема: "Prisma Client initialization error"
**Решение:**
\`\`\`bash
npx prisma generate
npm run dev
\`\`\`

### Проблема: "Database connection error"
**Решение:**
- Проверьте DATABASE_URL в .env
- Убедитесь, что PostgreSQL запущен
- Проверьте логин/пароль базы данных

### Проблема: Middleware редирект loop
**Решение:**
- Проверьте NEXTAUTH_URL в .env
- Очистите cookies браузера
- Перезапустите dev сервер
