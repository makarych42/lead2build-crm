# Развертывание Lead2Build CRM на Vercel

## 🚀 Пошаговая инструкция

### Шаг 1: Регистрация на Vercel

1. **Зайдите на [vercel.com](https://vercel.com)**
2. **Нажмите "Sign Up"**
3. **Войдите через GitHub** (используйте ваш аккаунт makarych42)
4. **Подтвердите разрешения** для доступа к репозиториям

### Шаг 2: Подключение репозитория

1. **Нажмите "New Project"**
2. **Найдите репозиторий** `makarych42/lead2build-crm`
3. **Нажмите "Import"**
4. **Vercel автоматически определит** что это Next.js проект

### Шаг 3: Настройка проекта

#### 3.1 Основные настройки:
- **Framework Preset**: Next.js (автоматически)
- **Root Directory**: `construction-management`
- **Build Command**: `npm run build` (по умолчанию)
- **Output Directory**: `.next` (по умолчанию)

#### 3.2 Переменные окружения:
Добавьте следующие переменные в разделе "Environment Variables":

```
NODE_ENV=production
DATABASE_URL=postgresql://username:password@host:port/database
NEXTAUTH_SECRET=your-super-secret-key-change-this
NEXTAUTH_URL=https://your-project.vercel.app
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_WEBHOOK_URL=https://your-project.vercel.app/api/telegram/webhook
```

### Шаг 4: Настройка базы данных

#### Вариант A: Vercel Postgres (рекомендуется)
1. **В панели проекта** нажмите "Storage"
2. **Выберите "Postgres"**
3. **Создайте новую базу данных**
4. **Скопируйте DATABASE_URL** в переменные окружения

#### Вариант B: Внешняя база данных
- **Neon** (бесплатно): [neon.tech](https://neon.tech)
- **Supabase** (бесплатно): [supabase.com](https://supabase.com)
- **PlanetScale** (бесплатно): [planetscale.com](https://planetscale.com)

### Шаг 5: Развертывание

1. **Нажмите "Deploy"**
2. **Дождитесь завершения** сборки (2-3 минуты)
3. **Проверьте логи** на наличие ошибок

### Шаг 6: Подключение домена

#### 6.1 Настройка домена в Vercel:
1. **В настройках проекта** перейдите в "Domains"
2. **Добавьте домен**: `lead2build.ru`
3. **Добавьте поддомен**: `www.lead2build.ru`
4. **Vercel даст вам DNS записи** для настройки

#### 6.2 Настройка DNS в Рег.ру:
1. **Зайдите в панель управления** Рег.ру
2. **Найдите домен** lead2build.ru
3. **Перейдите в "DNS записи"**
4. **Добавьте записи** которые дал Vercel:

```
A     @         76.76.19.61
CNAME www       cname.vercel-dns.com
```

### Шаг 7: SSL сертификат

Vercel **автоматически** выдаст SSL сертификат через несколько минут после настройки DNS.

## 🚨 Решение проблем

### Ошибка сборки:
1. **Проверьте логи** в панели Vercel
2. **Убедитесь** что все переменные окружения настроены
3. **Проверьте** что база данных доступна

### Ошибка базы данных:
1. **Проверьте DATABASE_URL**
2. **Убедитесь** что база данных создана
3. **Выполните миграции** Prisma

### Ошибка домена:
1. **Подождите 24 часа** для распространения DNS
2. **Проверьте DNS записи** в Рег.ру
3. **Убедитесь** что домен добавлен в Vercel
